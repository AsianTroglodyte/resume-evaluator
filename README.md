## Resume Evaluator

Resume evaluator is an LMS-like website where students submit resumes to assignments and receive automated feedback on quality, ATS compatibility, and job-description keyword match.

Instructors create modules and assignments; each submission runs evaluation at turn-in time and stores frozen feedback for review. **Polished MVP** scope is documented in `CONTEXT.md` (assignment-level due dates and resubmission rules; no per-student overrides). On-site mock listings use **claims** with capacity (see ADR `0007`; deferred until after paste-JD MVP). Personal workspaces support optional **practice** (paste JD, or later practice against a claimed listing) and are not part of the assignment submit path.
